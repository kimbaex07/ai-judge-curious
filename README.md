A short text written to make an AI judge curious. A lighthouse keeper finds a letter in a bottle, addressed to someone who hasn't been born yet — and the handwriting is his own. One small mystery, left open on purpose: who wrote it, and what did the sea give back?

`main.py` (pure Python standard library, no network) writes the text to `/output/entry.txt`. It is 263 characters, inside the contest's 1–280 limit.

## Run it

```sh
python3 main.py
```
